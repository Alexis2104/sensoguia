# SensoGuía

Herramienta web para identificar sensores y visualizar sus características técnicas en el laboratorio de electrónica.

Proyecto de graduación — Ingeniería en Sistemas de Información y Ciencias de la Computación, Universidad Mariano Gálvez de Guatemala, sede Cobán (2026). Autor: Alexis David Macz Maldonado.

Este repositorio contiene solo la versión compilada que se publica en GitHub Pages: https://alexis2104.github.io/sensoguia/
